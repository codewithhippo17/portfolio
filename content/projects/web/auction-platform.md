## Overview

This project is a fully functional real-time auction platform designed to handle live bidding. It allows users to list items, set starting prices and timers, and place bids against other users in real-time without needing to refresh the page.

## Features

- **Real-Time Bidding**: Powered by WebSockets to ensure that bids are updated instantly across all connected clients.
- **Authentication**: Secure user login and registration to ensure bids are placed by verified individuals.
- **Countdown Timers**: Accurate server-synchronized timers that automatically close auctions when time expires.
- **Dashboard**: A clean, intuitive UI for users to track their active bids, won items, and listed auctions.
- **Responsive Design**: Built with TailwindCSS to provide a seamless experience on both desktop and mobile devices.
