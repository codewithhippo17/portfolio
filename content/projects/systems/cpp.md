## Overview

The CPP project series from 42 School is a deep dive into Object-Oriented Programming (OOP) using C++. Across multiple modules, it explores core paradigms of C++98, focusing on memory management, classes, templates, and the Standard Template Library (STL).

## Features

- **Classes and Objects**: Encapsulation, initialization, and memory allocation.
- **Inheritance & Polymorphism**: Abstract classes, interfaces, and virtual functions.
- **Exceptions**: Robust error handling mechanisms.
- **Templates**: Generic programming for data structures and algorithms.
- **STL**: Mastery of C++ Standard Template Library containers, iterators, and algorithms.
