## Overview

Libft is the foundational project at 42 School. The goal is to recreate a custom C standard library from scratch. This library is then used throughout all subsequent C projects in the curriculum.

## Features

- **Memory Management**: `malloc`, `free`, `memset`, `bzero`, `memcpy`, `memmove`.
- **String Manipulation**: `strlen`, `strcpy`, `strjoin`, `strtrim`, `split`.
- **Character Checks**: `isalpha`, `isdigit`, `isalnum`, `isascii`, `toupper`, `tolower`.
- **Linked Lists**: Implementation of a generic singly-linked list and its associated operations (`lstnew`, `lstadd_front`, `lstmap`, etc.).
