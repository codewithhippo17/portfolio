## Overview

`push_swap` is a highly algorithmic project from the 42 curriculum. The objective is to sort a random list of integers using two stacks (`Stack A` and `Stack B`) and a very specific, limited set of operations (push, swap, rotate, and reverse rotate). 

The true challenge of this project isn't just sorting the numbers, but sorting them using the **absolute minimum number of operations** possible.

## Features

- **Custom Data Structures**: Implementation of highly efficient linked lists or arrays to represent the two stacks.
- **Algorithm Optimization**: Designing a sorting algorithm (often variations of Radix sort, Quick sort, or custom chunking algorithms) tailored for the unique constraints of the stack operations.
- **Complexity Management**: Handling different edge cases effortlessly, from tiny sets of numbers (3 to 5 elements) to massive sets (100 to 500 elements) while staying under strict operation limits.
- **Performance Tuning**: Benchmarking and tweaking the logic to shave off every unnecessary move to get the highest possible grade.
